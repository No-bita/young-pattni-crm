# Template inspection diagnostic

A login-protected diagnostic view shows a redacted summary of existing template information. It is separate from campaign sending and does not send messages or change templates.

The diagnostic is off by default. Enabling it requires a separately approved, short-lived scope. It does not download media or establish whether a sample image can be reused.
